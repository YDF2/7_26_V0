# 2026-04-18 裁判盒队伍号与机器人号参数映射核查日志

## 背景
为确认机器人连接裁判盒（GameController）时“队伍号码”和“机器人号码”的正确配置来源，对控制器启动链路、配置读取链路、GC 收发链路进行一次代码级核查。

## 结论摘要
1. 队伍号码对应参数：`team_number`（位于 `src/data/config.conf`）。
2. 机器人号码对应运行参数：启动参数 `--player`（或 `-p`），进入程序后对应 `CONF->id()`。
3. `players` 节中的键（如 `"0"`、`"1"`、`"2"`）不是裁判盒直接读取字段，但会被 `CONF->id()`拼接为 `players.<id>` 用来加载该机器人配置。
4. 裁判盒回传包中：
   - `playerNum = CONF->id()`
   - `teamNum = team_number`

## 关键代码证据

### 1) 配置文件参数定义
文件：`src/data/config.conf`
- `team_number`: 队伍号（示例当前值为 2）
- `players`: 机器人分配置表（以机器人编号为键）
- `kickoff_id`、`keeper_id`: 在当前代码中未形成“裁判盒机器人号码”的主链路

### 2) 启动参数决定机器人号码
文件：`src/controller/options/options.cpp`
- 通过命令行参数读取机器人号：`id_ = arg<int>("player")`

文件：`src/controller/main.cpp`
- 初始化配置时将启动参数传入：`CONF->init(OPTS->id())`

文件：`src/lib/configuration.hpp`
- `Configuration::init(const int &id)` 中保存：`id_ = id`
- 同时设置 `player_ = "players." + std::to_string(id_)`
- 对外暴露 `id()` 供全局使用

### 3) 裁判盒收包与队伍匹配
文件：`src/controller/player/sensor/gamectrl.cpp`
- 从 UDP 3838 接收 `RoboCupGameControlData`

文件：`src/controller/player/play_with_gc.cpp`
- 使用 `CONF->team_number()` 和 `gc_data.teams[*].teamNumber` 进行我方队伍索引判断
- 罚下状态读取：`gc_data.teams[team_index].players[CONF->id() - 1].penalty`

### 4) 裁判盒回传包中的号码字段
文件：`src/controller/player/task/gcret_task.hpp`
- `ret_data.playerNum = static_cast<uint8_t>(CONF->id())`
- `ret_data.teamNum = CONF->get_config_value<uint8_t>("team_number")`

文件：`src/lib/udp_data/RoboCupGameControlData.h`
- 协议注释明确：`playerNum` 为从 1 开始的机器人号，`teamNum` 为队伍号

## 参数对应关系（最终）

| 显示项（裁判盒） | 代码实际来源 | 配置/启动入口 |
|---|---|---|
| 队伍号码 teamNum | `CONF->team_number()` | `src/data/config.conf` 的 `team_number` |
| 机器人号码 playerNum | `CONF->id()` | 启动参数 `--player/-p`，并映射到 `players.<id>` 子配置 |

## 使用建议
1. 比赛前先确认 `src/data/config.conf` 中 `team_number` 与赛事分配一致。
2. 启动每台机器人时显式传入正确的 `--player`，避免默认值 0 导致号码不匹配。
3. 若赛事要求机器人号从 1 开始，建议统一使用 1..N 作为启动参数，并检查 `players` 键是否同步。

## 风险与注意点
1. 当前存在 `CONF->id() - 1` 索引访问（读取 penalty），若机器人号为 0 会访问越界前一位，存在风险。
2. `kickoff_id` 在当前仓库未检索到有效使用路径；`keeper_id` 仅有读取接口，未形成主流程控制。
3. 现有配置中的 `players` 键包含 `"0"`，与协议中 playerNum 从 1 开始的约定存在语义差异，建议统一规范。

## 本次结论可执行版本
- 你要对接裁判盒时：
  - 队伍号码改 `team_number`
  - 机器人号码改启动参数 `--player`
- `players` 节对应的是该机器人本地配置分支，不是直接发送到裁判盒的字段。
